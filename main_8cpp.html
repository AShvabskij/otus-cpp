Detailed Description

ДЗ "Реализовать функцию печати условного IP-адреса".

Этот файл содержит реализацию функций путём использования механизма SFINAE для вывода IP-адресов, представленных в различных типах данных: целые числа, строки, контейнеры и кортежи.

Печатает IP-адрес из целочисленного значения

Преобразует целое число в октеты IP-адреса в порядке от старшего байта к младшему и выводит их через точку.

Template Parameters
TЦелочисленный тип (int8_t, int16_t, int32_t, int64_t и т.д.)
Parameters
numberЧисловое представление IP-адреса
Note
Поддерживаются только целочисленные типы
Warning
Для знаковых типов может потребоваться приведение к беззнаковому

Пример использования:

print_ip(int32_t{2130706433}); // Выведет "127.0.0.1"
